inverse_kinematics_2dof.cpp 
This file contains a cpp simple inverse kinematics solver for a 2dof robotic arm on the 1st quadrant of the x-y plane.
Each of the two sections of the robotic arm are of equal lengths, which you are prompted to input upon running the code.

temperatura_convert.cpp
This file contains a simple cpp code to in-between Celsius, kelvin and fahrenheit.
